# Contributing

Thank you for considering a contribution to `b2b-ai-website-remodel`.

This project is intentionally focused. It is not a generic SEO checklist, website builder, ad tool, or content generator. Contributions should strengthen B2B AI website remodeling, evidence-aware trust, and buyer decision clarity.

## Good Contributions

- Improve the entity, product fact, trust signal, evidence gap, buyer decision, or GEO/AI readability frameworks.
- Add practical examples for B2B manufacturers, suppliers, distributors, industrial service providers, or export companies.
- Improve safety rules that prevent unsupported claims.
- Improve helper scripts without making them dependent on private services.
- Improve documentation clarity for Codex users.

## Avoid

- Ranking guarantees.
- AI citation guarantees.
- Fake proof, fake cases, fake certification examples, or unsupported company facts.
- Generic SEO keyword stuffing.
- Industry claims that require legal, compliance, or certification review unless clearly framed as owner-confirmed evidence.

## Pull Request Guidelines

1. Keep changes focused.
2. Preserve the skill name: `b2b-ai-website-remodel`.
3. Keep the Skill modular. Put detailed method content in `references/`, not directly into `SKILL.md`, unless it is essential workflow guidance.
4. Do not add private customer data, credentials, API keys, or unpublished business materials.
5. Run the Codex skill validator before submitting:

```powershell
python C:\Users\Administrator\.codex\skills\.system\skill-creator\scripts\quick_validate.py .\skills\b2b-ai-website-remodel
```

## Issue Guidelines

When opening an issue, include:

- Website type or industry context.
- Whether the issue is about audit, planning, execution, CMS-safe work, or helper scripts.
- Expected behavior.
- Actual behavior.
- Any public example page or sanitized sample input.
