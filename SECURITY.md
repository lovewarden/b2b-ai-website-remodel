# Security Policy

## Supported Versions

The current public version is:

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

## Reporting Security Issues

Please do not publish security-sensitive reports in public issues.

If you discover a vulnerability or a private-data exposure risk, open a private security advisory on GitHub if available, or contact the repository maintainer through the public ShenGEO website:

https://www.shengeo.com/

## Data Safety

This skill should not contain:

- API keys
- Passwords
- Customer private data
- Private server credentials
- Unpublished business documents
- Certification documents not intended for public release

When using the skill on a real website, keep sensitive owner materials out of public repositories unless explicitly approved for publication.
