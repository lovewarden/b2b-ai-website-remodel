# SEO Preservation

GEO, AEO, and AI readability improvements must strengthen traditional SEO, not replace it. Do not make a site easier for AI while making it worse for search engines or buyers.

## Pre-Edit SEO Snapshot

Before meaningful edits, record what exists:

- URL path and slug.
- Title tag.
- Meta description.
- Canonical tag.
- H1 and major H2s.
- Index/noindex and robots directives.
- Existing structured data.
- Primary navigation and internal links.
- Sitemap and robots references.
- Existing image alt patterns.

If Search Console, analytics, rankings, or high-traffic page data are available, protect those pages especially.

## Do Not Break

Avoid accidental changes to:

- Existing URLs, unless a redirect plan is approved.
- Canonical URLs.
- `robots.txt` and `noindex` directives.
- Sitemap inclusion.
- Existing ranking page intent.
- Contact forms, inquiry buttons, phone/email/WhatsApp links.
- Hreflang and multilingual relationships.
- Product/category navigation.

## Title And Description Rules

Improve titles and descriptions conservatively:

- Keep the primary product/category intent.
- Put the concrete product or category before vague brand slogans.
- Do not keyword-stuff.
- Do not overpromise certifications, prices, countries, capacity, or delivery.
- Make descriptions useful for buyers and truthful for snippets.

## Heading Rules

Good B2B H1 pattern:

```text
[Product Category] Manufacturer for [Application/Buyer Type]
```

Only use this if manufacturer status and product category are verified.

Avoid:

- Multiple unrelated H1s.
- Slogan-only H1s such as "Quality First, Customer First".
- Removing existing headings that carry search intent.

## Internal Link Rules

Add helpful links:

- Home to product categories.
- Product category to product detail pages.
- Product pages to capabilities, FAQ, contact, catalog, and applications.
- FAQ to relevant products.

Do not create large footer link dumps or irrelevant exact-match anchor spam.

## URL Change Rule

Default: do not change URLs.

If URL changes are necessary:

- List old and new URLs.
- Add 301 redirect instructions.
- Update internal links.
- Update sitemap.
- Check canonical tags.
- Tell the user this is higher risk.
